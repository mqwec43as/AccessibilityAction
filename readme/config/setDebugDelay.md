# [setDebugDelay](/code/config/setDebugDelay.bsh)

Set the highlight duration used by debug mode.

&nbsp;
# Dependencies
1. [Config](/readme/config/Config.md)

&nbsp;
# How it works
`setDebugDelay` updates the `debugDelay` value used by the A11y configuration so debug highlights last for the chosen duration.

&nbsp;
# How to use

```java
setDebugDelay(1000);
```

&nbsp;
## Return Value
Returns the new duration value that was set.
