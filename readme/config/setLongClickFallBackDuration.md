# [setLongClickFallBackDuration](/code/config/setLongClickFallBackDuration.bsh)

Set the fallback duration for long-click behavior.

&nbsp;
# Dependencies
1. [Config](/readme/config/Config.md)

&nbsp;
# How it works
`setLongClickFallBackDuration` updates the fallback period used when a long-click action needs to trigger after a manual delayed press.

&nbsp;
# How to use

```java
setLongClickFallBackDuration(750);
```

&nbsp;
## Return Value
Returns the duration value that was set.
