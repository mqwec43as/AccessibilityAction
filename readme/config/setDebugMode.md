# [setDebugMode](/code/config/setDebugMode.bsh)

Enable or disable the runtime debug mode.

&nbsp;
# Dependencies
1. [Config](/readme/config/Config.md)

&nbsp;
# How it works
`setDebugMode` toggles the `debugMe` flag in the active configuration object, enabling or disabling debug behavior.

&nbsp;
# How to use

```java
setDebugMode(true);
```

&nbsp;
## Return Value
Returns the boolean state that was set.
