# [setFindDelay](/code/config/setFindDelay.bsh)

Set the duration that node find hints remain visible.

&nbsp;
# Dependencies
1. [Config](/readme/config/Config.md)

&nbsp;
# How it works
`setFindDelay` updates the `findDelay` value used when a node match is highlighted during searching.

&nbsp;
# How to use

```java
setFindDelay(200);
```

&nbsp;
## Return Value
Returns the new delay value.
