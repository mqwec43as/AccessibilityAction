# [setStepDelay](/code/config/setStepDelay.bsh)

Set the delay between debug steps.

&nbsp;
# Dependencies
1. [Config](/readme/config/Config.md)

&nbsp;
# How it works
`setStepDelay` updates the pause used between step-by-step debug actions so each interaction can be inspected visually.

&nbsp;
# How to use

```java
setStepDelay(150);
```

&nbsp;
## Return Value
Returns the new step delay.
