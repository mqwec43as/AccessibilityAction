# [showDisplaySteps](/code/config/showDisplaySteps.bsh)

Toggle display tracing for step-by-step debugging.

&nbsp;
# Dependencies
1. [Config](/readme/config/Config.md)

&nbsp;
# How it works
`showDisplaySteps` enables or disables the `debugSteps` setting so each debug step can be shown while execution is traced.

&nbsp;
# How to use

```java
showDisplaySteps(true);
```

&nbsp;
## Return Value
Returns the boolean state that was set.
