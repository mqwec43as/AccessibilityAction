# [a11E](/code/event/a11E.bsh)

Manage accessibility-event listeners, event filters, event history, and monitor state.

&nbsp;
# Dependencies
1. Android `AccessibilityEvent`
2. [validate](/readme/lib/validate.md)
3. [startMonitor](/readme/event/startMonitor.md)
4. RxJava and a single event-dispatch executor

&nbsp;
# How it works
`a11E()` creates a scripted event manager and stores listeners by event ID. When a listener is added, its `on<EventName>(AccessibilityEvent)` methods are converted to Android event-type constants and its package filters are compiled. The manager tracks the active event list, dispatch history, ignored packages, mute state, and the RxJava monitor subscription.

Listeners are added with `add(String eventId, This eventListener)` and removed with `remove(String eventId)`. `getEvents(int eventType, String packageName)` applies event-type, package, ignored-package, and global ignore filters before returning matching listeners. `mute()` and `unmute()` temporarily stop dispatch without removing listeners.

&nbsp;
# How to use

```java
a11E = a11E();
listener() {
    String PackageName = ".*taskerm.*";
    onViewClicked(Object event) {
        click("Settings");
    }
    return this;
}
a11E.add("settingsClick", listener());
```

```java
a11E.remove("settingsClick");
a11E.mute();
a11E.unmute();
```

The global runtime normally exposes the manager through `a11Y.addEvent(...)`, `a11Y.removeEvent(...)`, and `a11Y.removeEvents()`.

&nbsp;
## Return Value
Returns a scripted `a11E` object. `add`, `remove`, `mute`, and `unmute` update manager state; `getEvents(...)` returns a filtered listener list; `isMuted()` returns a boolean; and `get(String eventId)` returns the registered listener or `null`.
