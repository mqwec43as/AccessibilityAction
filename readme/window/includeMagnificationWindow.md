# [includeMagnificationWindow](/code/window/includeMagnificationWindow.bsh)

Include magnification overlay windows in the current filter.

&nbsp;
# Dependencies
1. [WindowInfo](/readme/window/WindowInfo.md)
2. [addWindowFilter](/readme/window/addWindowFilter.md)

&nbsp;
# How it works
`includeMagnificationWindow` adds the magnification overlay window type so magnifier windows can be matched.

&nbsp;
# How to use

```java
includeMagnificationWindow();
```

&nbsp;
## Return Value
Returns the updated filter bitmask.
